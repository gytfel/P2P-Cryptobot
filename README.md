# P2P-Cryptobot

Парсер P2P-маркета [CryptoBot](https://t.me/CryptoBot) в Telegram. Он ищет самые выгодные
объявления на **покупку** и **продажу** монет и сравнивает их с **реальным рыночным курсом**,
а не со средней ценой самого CryptoBot. На CryptoBot монеты обычно продают дороже рынка,
поэтому эталон берётся с бирж.

Пример на демо-данных из `examples/` (курс задан вручную):

```
=== USDT/RUB ==================================================
Рыночный курс USDT/RUB: 95.50 RUB (задан вручную)

  #  Мерчант        Цена  С комисс.  Выгода  К медиане  Прибыль         Лимиты  Доступно     Сделки  Оплата
  -  ------------  -----  ---------  ------  ---------  -------  -------------  --------  ---------  -------------
  1  ivan_p2p      95.10      95.10  +0.42%     +1.17%       84   5 000–50 000    600.00    312/97%  Сбербанк
  2  fast_usdt     96.40      96.40  -0.94%     -0.18%     -187  1 000–150 000  2 500.00    840/99%  СБП, Т-Банк
  3  crypto_mama   97.85      97.85  -2.46%     -1.69%     -480     500–30 000  1 200.00  1540/100%  СБП

CryptoBot: 4 объявл., медиана 94.80 RUB (-0.73% к рынку), дороже всех: 96.30
  #  Мерчант      Цена  С комисс.  Выгода  К медиане  Прибыль          Лимиты  Доступно    Сделки  Оплата
  -  ----------  -----  ---------  ------  ---------  -------  --------------  --------  --------  -----------
  1  rich_buyer  96.30      95.34  -0.17%     +1.58%      -34  10 000–500 000  8 000.00   410/99%  Т-Банк, СБП

```

С реальным курсом вместо «задан вручную» выводятся котировки по источникам, например
`USDT/RUB: rapira 95.48 ✓ | coingecko 95.60 ✓ | bybit_p2p 95.41 ✓` (✗ — выброс, не учтён).

## Как считается выгода

**Реальный курс** = медиана(спот монета/USDT) × медиана(USDT/фиат):

| Что | Источники |
|---|---|
| монета/USDT (для USDT = 1) | Binance, Bybit, OKX, CoinGecko |
| USDT/фиат | Rapira (биржа с парой USDT/RUB), CoinGecko, середина P2P-стакана Bybit, курс конвертации самого CryptoBot (Crypto Pay API, если задан токен), по желанию курс ЦБ РФ |

Если источник отклоняется от медианы больше чем на `max_spread_pct` (по умолчанию 3%), он
считается выбросом и не учитывается. Если какой-то источник недоступен, расчёт идёт по остальным.

**Выгода сделки** считается с учётом комиссии CryptoBot (по умолчанию покупателю 0%, продавцу 1%):

* покупка: `эфф. цена = цена / (1 − комиссия)`, `выгода = (рынок − эфф. цена) / рынок`;
* продажа: `эфф. цена = цена × (1 − комиссия)`, `выгода = (эфф. цена − рынок) / рынок`.

Плюс означает, что сделка лучше рынка, минус означает переплату или недополучение. Колонка
«К медиане» показывает, насколько объявление лучше типичной цены на CryptoBot. «Прибыль» — это
выигрыш в фиате на сумму `--amount` относительно рынка.

Объявления с ценой дальше 30% от рынка отбрасываются как ошибка или приманка. Если задан
`--amount`, остаются только объявления, в лимиты и остаток которых эта сумма помещается.

## Установка

Нужен Python 3.10+ (на 3.10 дополнительно ставится `tomli`).

```bash
git clone https://github.com/gytfel/P2P-Cryptobot.git
cd P2P-Cryptobot
pip install -r requirements.txt
cp config.example.toml config.toml
```

Проверить работу на демо-данных (выдуманные объявления, курс задан вручную):

```bash
python -m p2p_scanner --rate 95.5 --amount 20000 \
  --offers-json buy=examples/sample_buy.json --offers-json sell=examples/sample_sell.json
```

Проверить реальный курс:

```bash
python -m p2p_scanner rates --coin USDT,TON,BTC --fiat RUB
```

## Подключение к CryptoBot

У CryptoBot нет публичного API для объявлений P2P: маркет работает внутри мини-приложения
(`t.me/send/app?startapp=p2p`), а Crypto Pay API отдаёт только курсы конвертации. Поэтому
парсер повторяет тот же запрос, который делает мини-приложение. Его нужно один раз скопировать:

1. Откройте в Chrome/Edge [web.telegram.org](https://web.telegram.org) и войдите в аккаунт.
   Вместо этого можно взять Telegram Desktop: включите отладку webview в *Настройки →
   Продвинутые → Экспериментальные настройки*, затем в мини-приложении выберите ПКМ → «Inspect».
2. Откройте @CryptoBot → P2P Маркет.
3. Нажмите F12, перейдите на вкладку **Network** и включите фильтр **Fetch/XHR**.
4. В мини-приложении откройте «Купить» → USDT → RUB. В списке запросов найдите тот, у которого
   во вкладке **Response** лежит список объявлений (цены, ники, лимиты).
5. Выберите ПКМ → **Copy → Copy as cURL (bash)** и сохраните команду в файл `cryptobot_request.txt`.
6. Замените в файле конкретные значения на плейсхолдеры:
   * монету (`"USDT"`) на `{{coin}}`, фиат (`"RUB"`) на `{{fiat}}`;
   * тип объявления на `{{side}}`. Посмотрите, что приложение отправляет на вкладках «Купить» и
     «Продать», и пропишите эти значения в `config.toml`, например
     `side_values = { buy = "SALE", sell = "PURCHASE" }`;
   * для нескольких страниц: смещение на `{{offset}}` (или номер страницы на `{{page}}`),
     размер страницы на `{{limit}}`, затем задайте `pages` в конфиге.

   Есть и другие плейсхолдеры: `{{coin_lower}}`, `{{fiat_lower}}`, `{{side_lower}}`,
   `{{side_upper}}` и `{{amount}}`. Пример шаблона лежит в `cryptobot_request.example.txt`.
   Можно не править файл, а сохранить два запроса без плейсхолдеров:
   `request_files = { buy = "curl_buy.txt", sell = "curl_sell.txt" }`.
7. Проверьте, как разбирается ответ:

   ```bash
   python -m p2p_scanner inspect --side buy
   ```

   Команда покажет найденный список объявлений и разобранные поля. Если что-то определилось
   неверно, задайте путь вручную в `[cryptobot.fields]` (например `price = "price.value"`). Для
   этого удобно посмотреть сырой ответ: `inspect --raw`. Можно разобрать и сохранённый ответ:
   `inspect --file response.json`.

Авторизация в скопированном запросе со временем устаревает. Если парсер пишет «авторизация
устарела», откройте P2P-маркет заново и скопируйте свежий запрос.

## Использование

```bash
# Лучшие сделки на покупку и продажу USDT за рубли
python -m p2p_scanner

# Сделка на 20 000 ₽, только СБП, только сделки не хуже рынка, топ-5
python -m p2p_scanner --amount 20000 --pay СБП --min-profit 0 --top 5

# Только продажа, несколько монет, выгрузка в CSV (открывается в Excel)
python -m p2p_scanner --side sell --coin USDT,TON --csv deals.csv

# Свой курс вместо бирж
python -m p2p_scanner --rate 96.1
```

| Параметр | Что делает |
|---|---|
| `--coin`, `--fiat` | монеты и фиаты через запятую |
| `--side buy\|sell\|both` | buy — я покупаю монету, sell — я продаю |
| `--amount` | сумма сделки в фиате: фильтр по лимитам и расчёт прибыли |
| `--min-profit` | порог выгоды, %. Может быть отрицательным: `-0.5` значит «не хуже рынка на 0.5%» |
| `--pay` | способы оплаты (подстрока) |
| `--min-orders`, `--min-completion` | надёжность мерчанта |
| `--buy-fee`, `--sell-fee` | комиссии, % |
| `--rate` | рыночный курс вручную |
| `--offers-json buy=FILE` | взять объявления из сохранённого JSON |
| `--json`, `--csv` | сохранить результаты |
| `--watch [N]` | повторять каждые N секунд |
| `--notify`, `--alert-pct` | уведомления в Telegram |

Все параметры можно задать в `config.toml`; описание каждого есть в `config.example.toml`.

## Мониторинг с уведомлениями в Telegram

1. Создайте бота у [@BotFather](https://t.me/BotFather) и напишите ему что-нибудь.
2. Узнайте свой `chat_id`, например у [@userinfobot](https://t.me/userinfobot).
3. Запустите мониторинг:

```bash
export TELEGRAM_BOT_TOKEN=123456:ABC...
export TELEGRAM_CHAT_ID=123456789
python -m p2p_scanner --watch 60 --notify --alert-pct 0.5
```

Каждые 60 секунд парсер проверяет маркет и присылает объявления с выгодой от 0.5% к рынку.
О каждом объявлении он сообщает один раз.

Курс конвертации самого CryptoBot тоже можно учитывать. Для этого создайте приложение в
@CryptoBot → Crypto Pay → Create App и задайте `export CRYPTO_PAY_TOKEN=...`.

## Важно

* Файлы `cryptobot_request.txt` и `config.toml` содержат вашу авторизацию Telegram. Не
  публикуйте их: они уже добавлены в `.gitignore`.
* Парсер только читает объявления. Сделки он не открывает и деньги не переводит.
* Внутреннее API мини-приложения не документировано и может измениться. Тогда перескопируйте
  запрос и проверьте разбор через `inspect`.
* Не ставьте слишком частый `--watch`: 30–60 секунд достаточно, при частых запросах аккаунт
  могут ограничить.
* Некоторые биржи недоступны из отдельных стран. Команда `rates` покажет, какие источники
  ответили; ненужные можно убрать в `[rates]`.

## Разработка

```bash
pip install -r requirements-dev.txt
python -m pytest
```

Структура:

* `p2p_scanner/curl.py` — разбор «Copy as cURL» и подстановка плейсхолдеров;
* `p2p_scanner/cryptobot.py` — запросы к мини-приложению CryptoBot и пагинация;
* `p2p_scanner/extract.py` — автоопределение списка объявлений и полей в JSON;
* `p2p_scanner/rates.py` — реальный курс с бирж и отбрасывание выбросов;
* `p2p_scanner/analyzer.py` — расчёт выгоды, фильтры, ранжирование;
* `p2p_scanner/report.py`, `notify.py`, `cli.py` — вывод, Telegram, командная строка.
